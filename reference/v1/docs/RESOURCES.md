# Resource integration log

All accessed 2026-11-14. Decision per resource: INTEGRATE / VALIDATE-AGAINST / REFERENCE / REJECT.

| Resource | URL | Decision | What was read and found |
|---|---|---|---|
| JPL Horizons API | https://ssd-api.jpl.nasa.gov/doc/horizons.html | **VALIDATE-AGAINST** | Endpoint `https://ssd.jpl.nasa.gov/api/horizons.api`. A lunar surface observer works with `CENTER='coord@301'`, `COORD_TYPE='GEODETIC'`, `SITE_COORD='E-lon,lat,alt_km'`; the response header confirms `Center pole/equ: MEAN_ME` and radii 1737.4 km, i.e. the same frame and sphere as this project. The doc states no rate limit; the client sends one request at a time, ≥1.5 s apart, and caches every response on disk. Used only as an independent check (V2, V3), not at runtime. |
| NAIF / SPICE generic kernels | https://naif.jpl.nasa.gov/naif/data.html | **INTEGRATE** | Primary ephemeris engine. Kernels used: `naif0012.tls`, `pck00011.tpc`, `moon_pa_de440_200625.bpc`, `moon_de440_250416.tf` (defines MOON_ME), `de440s.bsp`. Downloaded but not yet used: `earth_1962_260806_2126_combined.bpc`. Station kernels exist as `earthstns_itrf93_260814.bsp` and `earth_topo_260814.tf` (the 201023 names in older tutorials now live under `a_old_versions/`). |
| LOLA south-pole DEMs (PGDA product 90) | https://pgda.gsfc.nasa.gov/products/90 | **INTEGRATE** | Barker et al. 2023 (PSJ 4, 183). Cloud-optimised GeoTIFFs, south polar stereographic metres, MOON_ME (DE421), sphere 1737.4 km (confirmed from the file's CRS: IAU 30135, latitude of origin −90°, central meridian 0°). Heights in metres, float32, NaN = void. Used: `LDEM_80S_80MPP_ADJ.TIF` (terrain truth), `..._ERR.TIF` (1-sigma height error → uncertainty band), `LDEM_60S_240MPP_ADJ.TIF` (far field beyond 80°S). Downloaded, not used: `..._HILL.TIF` (the app shades its own relief). 20 m and 10 m products exist (2.6–4.8 GB) and are the obvious next step for hero sites. |
| NASA Moon Trek | https://trek.nasa.gov/moon/ · https://trek.nasa.gov/tiles/apidoc/trekAPI.html?body=moon | **INTEGRATE** | WMTS REST template `{endpoint}/1.0.0/{Style}/{TileMatrixSet}/{TileMatrix}/{TileRow}/{TileCol}.jpg`. Verified from the capabilities XML of `Moon/EQ/LRO_WAC_Mosaic_Global_303ppd_v02`: style `default`, matrix set `default028mm`, zoom 0–8, JPEG, 2×1 tiles at zoom 0 (geographic), `Access-Control-Allow-Origin: *`. A missing tile means no coverage. The API page is rendered by script, so the wider layer catalogue was not read; only this one layer is used. The service drops connections when hit quickly in sequence, so the app relies on Cesium's normal tile throttling. |
| Quickmap (LROC/ASU) | https://quickmap.lroc.asu.edu/ | **REFERENCE** | Not read in this session and not scraped. Intended for manual comparison (V12, not done). |
| Canadian Space Agency, Moon exploration | https://www.asc-csa.gc.ca/eng/astronomy/moon-exploration/ | **REFERENCE** | Not read in this session; no content from it is used. Education cards are not built. |
| LROC featured images | https://www.lroc.asu.edu/ | **INTEGRATE** (as citations) | Source of touchdown coordinates for IM-1, IM-2, Blue Ghost M1, Chandrayaan-3, SLIM and Chang'e 3–6. Quotes are stored per site in `data/sites_research.json`. |
| NSSDCA | https://nssdc.gsfc.nasa.gov/planetary/lunar/lunar_sites.html | **INTEGRATE** (as citations) | Apollo LM coordinates (LRO-derived) and landing times; Luna 9 (tracking-era, two decimals). Several NSSDCA catalogue pages returned errors. |
